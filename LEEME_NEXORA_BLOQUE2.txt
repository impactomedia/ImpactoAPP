IMPACTO NEXORA v1.9.0 — BLOQUE 2
===================================

SERVICIO PRINCIPAL + UPGRADES + PRECIOS FIJOS

1. Copia los archivos de este parche sobre tu proyecto local respetando exactamente las carpetas.
2. Sube los cambios a GitHub main.
3. Railway desplegará automáticamente.
4. NO agregues ningún comando a Pre-Deploy.
5. NO cambies el Start Command.
6. NO hay migración de base de datos.

DESPUÉS DEL DEPLOY:
A) Ve a Configuración > Productos/Servicios.
B) Configura el precio fijo USD de los paquetes que vayas a utilizar.
C) Abre un cliente/seguimiento.
D) Desde su ficha usa "Servicio principal / Upgrade".
E) Registra el plan, pago inicial y plan de cuotas.
F) Para un upgrade, Nexora mostrará solo planes de mayor precio y reconocerá automáticamente lo ya pagado.

IMPORTANTE:
Las compras adicionales siguen usando el flujo normal de Nueva Venta.
El siguiente bloque las separará y organizará explícitamente como compras adicionales.
